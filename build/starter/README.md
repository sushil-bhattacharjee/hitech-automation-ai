# Starter set

Saved work every install of hiTech Automation AI starts with: RESTCONF / NETCONF / XPath /
Python collections and environments, YANG repos, Terraform and Ansible projects.
At start-up the app copies into `~/.hitech_automation_ai/` every file here that you do not
have yet — once per `VERSION`. Your own files are never overwritten.
Made by `tools/export-starter.sh` on the maintainer's machine; secrets are blanked.
